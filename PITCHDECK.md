### SCid: The Universal Music Certificate

**SCid (SoundChain ID)** - Every track gets a unique, verifiable certificate.

```
Format: SC-POL-XXXX-XXXXXX

Example: SC-POL-A7B2-847291
         │   │    │     │
         │   │    │     └── Unique sequence number
         │   │    └──────── Track hash (first 4 chars)
         │   └───────────── Network (Polygon)
         └───────────────── SoundChain prefix
```

**No NFT Required. No Wallet Required. No Cost.**

### SCid Format Specification

```
SC-[NETWORK]-[HASH]-[SEQUENCE]

SC     = SoundChain prefix (constant)
NETWORK = POL (Polygon), ETH (Ethereum), etc.
HASH    = First 4 characters of track content hash
SEQUENCE = 6-digit unique sequence number

Example: SC-POL-A7B2-847291
```

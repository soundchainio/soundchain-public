🤖 MANAGED AGENTS INTEGRATION — Apr 9, 2026

Anthropic just launched Claude Managed Agents (public beta). We integrated it into the full SoundChain agent suite tonight.

WHAT CHANGED:
Agents now run autonomously in Anthropic's cloud. They get built-in bash, file I/O, and web search. They only call back to our server for SoundChain-specific stuff (MongoDB, OGUN contracts, IPFS, radio).

Before: we manually ran the Claude chat loop via raw fetch
After: Anthropic runs the loop, we just handle domain tools

WHAT WAS BUILT:
- @anthropic-ai/sdk installed
- 7 new library files in lib/managed-agents/
- 3 new API endpoints (/api/agent/managed/session, /agents, /status)
- SMITH session.ts updated with MANAGED mode
- FURL terminal gets "jack managed" command

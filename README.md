## 💰 Everyone Wins — Literally

### WIN-WIN Streaming Rewards

Every stream on SoundChain generates **OGUN tokens** for both creators AND listeners:

| Participant | NFT Track | Regular Track |
|-------------|-----------|---------------|
| **Creator** | 0.35 OGUN (70%) | 0.035 OGUN (70%) |
| **Listener** | 0.15 OGUN (30%) | 0.015 OGUN (30%) |
| **Total** | 0.50 OGUN | 0.05 OGUN |

**NFT tracks earn 10x more rewards!**
